# نظام قصر الرياض الدولي لإدارة الفنادق المؤسسي (Enterprise PMS)
**نظام تشغيلي متكامل ومستوحى من نطاق عمل Oracle OPERA Cloud ومخصص للمملكة العربية السعودية**

---

## 🌟 نظرة عامة على المشروع

نظام برمجي مؤسسي لإدارة الفنادق الكبرى في المملكة العربية السعودية (160+ غرفة)، مبني وفق بنية **Modular Monolith** حديثة لضمان أقصى درجات الأداء والأمان وسهولة التوسع، مع دعم كامل للغة العربية واتجاه RTL، والتوافق الصارم مع متطلبات:
1. **هيئة الزكاة والضريبة والجمارك (ZATCA):** الفوترة الإلكترونية المرحلة 1 و 2 وتوليد رمز الاستجابة السريعة (QR Code) المشفر بترميز TLV (Tag-Length-Value) Base64.
2. **منصة شموس والمتطلبات الأمنية والسياحية:** تسجيل بيانات الهوية الوطنية والإقامة وجوازات السفر مع أرقام الغرف وسجلات الإقامة اللحظية.
3. **الدورة التشغيلية الكاملة:** الغرف، الحجوزات، الاستقبال والتسكين، التدبير الفندقي والتفتيش، الصيانة، الفوترة والمحاسبة، المطاعم ونقاط البيع POS، المخزون، وسجل التدقيق الأمني.

## 👥 الأدوار الوظيفية المعتمدة (RBAC)

يتضمن النظام أنواع الحسابات المطلوبة مع حفظ المسميات كما طُلبت:

| اسم المستخدم | المسمى الوظيفي | الدور (Role) | الصلاحيات ونطاق العمل |
| :--- | :--- | :--- | :--- |
| `admin` | **مسؤول النظام العام** | `ADMIN` | كامل الصلاحيات الإدارية والتقنية وإدارة المستخدمين والنسخ الاحتياطي |
| `gm` | **المدير العام للفندق** | `GENERAL_MANAGER` | التقارير التنفيذية، المالية، المؤشرات (ADR, RevPAR, Occupancy)، والتدقيق |
| `reception` | **مسؤول الاستقبال والتسكين** | `RECEPTIONIST` | إدارة الحجوزات، التسكين (Check-in) المشروط بجاهزية الغرفة، وتسجيل المغادرة |
| `supervisor` | **مشرفة النظافة والتفتيش** | `HOUSEKEEPING_SUPERVISOR` | توزيع مهام التنظيف، فحص الغرف، اعتماد الجاهزية الرسمية، وطلب إعادة التنظيف |
| `cleaner1` | **المنظف** | `CLEANER` | واجهة مستقلة ومحمية: رؤية الغرف المسندة، بدء وإنهاء التنظيف، والإبلاغ عن الأعطال |
| `cushion_manager` | **مدير الكوشن** | `CUSHION_MANAGER` | حساب مخصص قابل لتهيئة الصلاحيات لإدارة العمليات والمخمليات الخاصة |
| `maintenance` | **فني الصيانة** | `MAINTENANCE_TECH` | استقبال بلاغات الأعطال، تحديث قطع الغيار، وإعادة الغرف للتشغيل بعد الإصلاح |
| `accountant` | **المحاسب المالي** | `ACCOUNTANT` | فواتير النزلاء (Folios)، التحصيل عبر مدى/البطاقات، مطابقة ZATCA، وسندات القبض |
| `chef_pos` | **مسؤول خدمات المطاعم** | `RESTAURANT_STAFF` | نقاط البيع POS، طلبات الأغذية والمشروبات، والتحميل المباشر على حساب الغرفة |

## ⚙️ مميزات التشغيل الحقيقي والأمان

1. **فصل حالات الغرف الرباعي:**
   - حالة الإشغال: `VACANT`, `OCCUPIED`, `RESERVED`, `CHECKED_OUT`
   - حالة النظافة: `PENDING_CLEANING`, `CLEANING_IN_PROGRESS`, `CLEANED`, `PENDING_INSPECTION`, `INSPECTED_PASSED`, `NEEDS_RECLEAN`
   - حالة الصيانة: `OPERATIONAL`, `UNDER_MAINTENANCE`, `AWAITING_PARTS`
   - حالة البيع: `AVAILABLE`, `OUT_OF_ORDER`
2. **منع التسكين في غرف غير جاهزة:** لا يمكن إجراء Check-in لأي غرفة قبل اجتياز التفتيش واعتماد المشرفة.
3. **دورة المغادرة الآلية:** بمجرد تسجيل المغادرة (Check-out)، تتحول الغرفة فوراً إلى "تحتاج تنظيف" وتنشأ مهمة تنظيف آلية في طابور المنظفين.
4. **منع الحجز المزدوج (Double-Booking Prevention):** فحص زمني ذكي بالمعاملات الذرية لمنع حجز نفس الغرفة لفترات متداخلة.
5. **منع تكرار الدفع (Idempotency Keys):** كل عملية دفع مسجلة بمفتاح فريد لمنع تكرار الخصم.
6. **بوابة المنظف المعزولة:** المنظف لا يرى أي إيرادات أو بيانات نزلاء حساسة أو فواتير.

## 🚀 تشغيل النظام

### 1. تثبيت الحزم (عند الحاجة):
```bash
npm install
```

### 2. تجهيز قاعدة البيانات والبيانات الأولية (160 غرفة والمستخدمين):
```bash
npx prisma generate
npx prisma db push
node prisma/seed.js
```

### 3. تشغيل الاختبارات الآلية:
```bash
npm test
```

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```
ثم افتح المتصفح على: `http://localhost:3000`
